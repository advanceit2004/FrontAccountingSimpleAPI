# Changelog

## v2.4-2.0-slim4 - In development

- Started a new Slim 4 JSON API for FrontAccounting 2.4.20 and PHP 8.4.
- Removed legacy Slim 2 route compatibility.
- Added token-based JSON API authentication.
- Added health and company endpoints.
- Added read endpoints for items, item categories, customers, suppliers, currencies, exchange rates, bank accounts, GL accounts, tax types, tax groups, and locations.
- Added write endpoints for item categories, items, customers, suppliers, journal entries, and stock adjustments.
